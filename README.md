🚀 Day 1 of Linux Basics: Breaking Free from the GUI & Unleashing the CLI! 🐧
Vikas Ratnawat 
CloudDevOpsHub Community 

If you want to excel in DevOps and Cloud Engineering, leaving the comfort of graphical interfaces behind is step number one. Today marked Day 1 of our 5-Day Linux Plan, and we went straight into the core architecture of operating systems. 

Here is a breakdown of what I learned and executed in today's session:

🧠 Key Takeaways:
• OS Architecture: Understood how the Kernel and Shell work together as a middle layer between hardware and application software. Fun fact: The Linux kernel is written 97.9% in C language for fast execution and direct hardware communication!
• Linux vs. Windows: Dissected why ~80% of production servers run Linux. It’s free, open-source, highly secure, lightweight, and supports 100+ concurrent users via SSH with a fast ~30-second boot time. Windows, while user-friendly, carries high license costs and resource overhead (~6 GB RAM for OS alone).
• Distribution Ecosystem: Explored the 4 major distribution families—Red Hat, Fedora, Debian, and Ubuntu.
• File System Layout: Navigated critical system directories like / (root), /etc (configuration files), /bin (executables), and /var/logs (log files).

💻 Hands-On Commands Executed & Practiced:
We spent significant time on the live terminal configuring and auditing the system using native utilities:
🔹 System Auditing: Used 'pwd' to verify directories, 'ls' to list contents, and 'df -h' to check disk and mount details.
🔹 File & Directory Operations: Created structural environments using 'mkdir' and empty file boundaries with 'touch'.
🔹 Log Monitoring & Inspection: Mastered viewing configurations with 'cat' and 'more'. Run 'tail -20f auth.log' to follow live log entries and combined it with 'grep "error" auth.log' to filter specific failure keywords in real-time.
🔹 Networking: Used 'hostname -I' to pull local private IPs and 'curl ifconfig.me' to fetch external internet-facing IPs.

Building these core Linux habits is non-negotiable for designing automated infrastructure and CI/CD pipelines down the road. The journey has just begun! 🔥
